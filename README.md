## 📖 About

This is a static website hosted on GitHub Pages that provides bilingual (English/German) documentation for the nJukebox project - a personal touch display hardware jukebox system.

### Features
- Bilingual inline translation system (EN/DE)
- Modern dark-themed documentation with sidebar navigation
- Responsive design optimized for desktop
- Language preference saved automatically

### Documentation Pages
- Getting Started / Erste Schritte
- Spotify Setup / Spotify-Einrichtung
- Admin Guide / Admin-Anleitung
- Configuration / Konfiguration
- Troubleshooting / Problembehandlung
