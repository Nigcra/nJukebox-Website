## 🚀 Features

- **Local Music Library**: MP3 collection management with metadata detection
- **Spotify Integration**: Premium account streaming integration (requires Widevine DRM support)
- **Touch-Friendly Interface**: Optimized for touch displays
- **Admin Controls**: PIN-protected management panel
- **GEMA Reporting**: Compliance features for German events
- **Multilingual**: English and German support
- **Auto-DJ**: Automatic playlist management
- **Visualizations**: Audio-reactive visual effects

## 💻 Quick Start

1. Clone the repository
2. Install Node.js dependencies: `npm install`
3. Add music files to `/music` directory
4. Start the server: `npm start` or run batch files
5. Open browser to `http://localhost:3000`
6. Access admin panel with PIN `1234` (change this!)

**Note for Spotify Integration**: Requires a modern browser with Widevine DRM support (Chrome, Firefox, Safari, Edge) and a Spotify Premium account.
