Spotify Premium erforderlich: Für die Spotify-Integration benötigen Sie ein Spotify Premium-Konto. Kostenlose Spotify-Konten können die Web Playback API nicht nutzen.
Widevine DRM erforderlich: Ihr Browser muss Widevine DRM unterstützen, damit die Spotify-Integration funktioniert. Moderne Browser wie Chrome, Firefox, Safari und Edge unterstützen dies standardmäßig. Bei älteren Browsern oder speziellen Konfigurationen könnte Widevine deaktiviert sein, was die Spotify-Wiedergabe verhindert.

Warum Spotify integrieren?

Die Spotify-Integration erweitert Ihre nJukebox um Millionen von Songs und bietet:

  • 🎵 Riesige Musikbibliothek: Zugriff auf über 50 Millionen Songs
  • 🔍 Erweiterte Suche: Finden Sie jeden Song, Künstler oder Album
  • 📊 Auto-Learning: Automatisches Hinzufügen beliebter Playlists
  • 🎧 Nahtlose Integration: Kombiniert mit Ihrer lokalen Musiksammlung

Voraussetzungen

  • Spotify Premium Konto
  • Laufende nJukebox-Installation
  • Admin-Zugriff auf nJukebox
  • Internetverbindung

Schritt 1: Spotify Developer App erstellen

1.1 Spotify Developer Dashboard öffnen

  1. Gehen Sie zu developer.spotify.com/dashboard
  2. Melden Sie sich mit Ihrem Spotify-Konto an
  3. Klicken Sie auf "Create an App"

1.2 App-Details eingeben

  • App Name: "nJukebox" (oder ein beliebiger Name)
  • App Description: "Digital Jukebox System"
  • Website: Lassen Sie leer oder geben Sie eine URL ein
  • Redirect URI: http://localhost:3000/spotify-callback
Wichtig: Die Redirect URI muss exakt http://localhost:3000/spotify-callback lauten, auch wenn Sie nJukebox später über das Netzwerk verwenden.

1.3 App-Einstellungen konfigurieren

  1. Akzeptieren Sie die Spotify-Nutzungsbedingungen
  2. Klicken Sie auf "Create"
  3. Notieren Sie sich die Client ID
  4. Klicken Sie auf "Show Client Secret" und notieren Sie sich das Client Secret
Sicherheit: Teilen Sie Ihr Client Secret niemals öffentlich! Es gewährt Zugriff auf Ihre Spotify-App.

Schritt 2: nJukebox konfigurieren

2.1 Config.json bearbeiten

  1. Öffnen Sie die Datei config.json im nJukebox-Verzeichnis
  2. Finden Sie den "spotify"-Abschnitt
  3. Fügen Sie Ihre Spotify-Daten ein:
{
  "spotify": {
    "clientId": "IHR_CLIENT_ID_HIER",
    "clientSecret": "IHR_CLIENT_SECRET_HIER",
    "redirectUri": "http://localhost:3000/spotify-callback"
  }
}

2.2 nJukebox neu starten

  1. Stoppen Sie nJukebox (Strg+C im Terminal)
  2. Starten Sie es neu mit npm start oder der Batch-Datei
  3. Warten Sie, bis der Server vollständig geladen ist

Schritt 3: Spotify-Verbindung herstellen

3.1 Admin-Panel öffnen

  1. Öffnen Sie nJukebox in Ihrem Browser
  2. Klicken Sie auf das Schloss-Symbol (🔒)
  3. Geben Sie Ihre Admin-PIN ein
  4. Gehen Sie zum Tab "Einstellungen"

3.2 Spotify verbinden

  1. Scrollen Sie zum Spotify-Bereich
  2. Klicken Sie auf "Mit Spotify verbinden"
  3. Sie werden zur Spotify-Anmeldeseite weitergeleitet
  4. Melden Sie sich an und gewähren Sie die Berechtigungen
  5. Sie werden zurück zu nJukebox geleitet
Erfolg! Wenn die Verbindung erfolgreich war, sehen Sie "Spotify: Verbunden" im Admin-Panel mit Ihrem Spotify-Benutzernamen.

Schritt 4: Spotify-Features testen

4.1 Suche testen

  1. Verwenden Sie die Suchleiste in nJukebox
  2. Suchen Sie nach einem Song, der nicht in Ihrer lokalen Sammlung ist
  3. Spotify-Ergebnisse werden mit einem Spotify-Symbol markiert

4.2 Auto-Learning nutzen

  1. Gehen Sie im Admin-Panel zum Tab "Auto-Learning"
  2. Klicken Sie auf "Party Hits" oder eine andere Kategorie
  3. Warten Sie, bis die Tracks geladen wurden
  4. Überprüfen Sie Ihre Bibliothek auf neue Tracks

Spotify-Features im Detail

Musikwiedergabe

  • Streaming: Spotify-Tracks werden direkt gestreamt
  • Qualität: Automatische Qualitätsanpassung je nach Verbindung
  • Pufferung: Intelligente Vorpufferung für reibungslose Wiedergabe

Auto-Learning Kategorien

  • 🎵 Party Hits: Beliebte Party- und Tanzmusik
  • 🍺 Schlager Party: Deutsche Partymusik und Schlager
  • 🕺 Dance Hits: Elektronische Tanzmusik und Club-Tracks
  • 🎉 Alle Party-Playlists: Alle Party-Kategorien auf einmal

Benutzerdefinierte Playlists

  1. Kopieren Sie eine Spotify-Playlist-URL
  2. Fügen Sie sie im Auto-Learning-Bereich ein
  3. Klicken Sie auf "Playlist hinzufügen"
  4. Die Tracks werden zur Bibliothek hinzugefügt

Problembehandlung

Verbindung fehlgeschlagen

  • Client ID prüfen: Stellen Sie sicher, dass die Client ID korrekt ist
  • Redirect URI: Muss exakt http://localhost:3000/spotify-callback sein
  • Premium-Konto: Überprüfen Sie, ob Sie Spotify Premium haben
  • Firewall: Stellen Sie sicher, dass Port 3000 erreichbar ist

Keine Spotify-Tracks gefunden

  • Internetverbindung: Überprüfen Sie die Verbindung
  • Token abgelaufen: Trennen Sie die Verbindung und verbinden Sie sich erneut
  • API-Limits: Warten Sie einige Minuten und versuchen Sie es erneut

Wiedergabe-Probleme

  • Gerät aktiv: Stellen Sie sicher, dass nJukebox das aktive Spotify-Gerät ist
  • Browser-Autoplay: Klicken Sie einmal auf die Seite, um Audio zu aktivieren
  • Mehrere Sitzungen: Schließen Sie andere Spotify-Apps
  • Widevine DRM: Überprüfen Sie, ob Widevine DRM in Ihrem Browser aktiviert ist (chrome://settings/content/protectedContent oder firefox://settings/privacy)

Netzwerk-Setup für Spotify

Redirect URI für Netzwerk-Zugriff

Wenn Sie nJukebox über das Netzwerk verwenden:

  1. Behalten Sie die Redirect URI als http://localhost:3000/spotify-callback
  2. Die Spotify-Authentifizierung muss auf dem Host-Computer erfolgen
  3. Nach der Authentifizierung funktioniert Spotify von allen Geräten

Produktions-Setup

Für eine permanente Installation:

  • Verwenden Sie eine feste IP-Adresse oder Domain
  • Aktualisieren Sie die Redirect URI entsprechend
  • Konfigurieren Sie HTTPS für zusätzliche Sicherheit
Tipp: Für Veranstaltungen können Sie Spotify-Tracks zur lokalen Bibliothek "cachen", um auch bei schlechter Internetverbindung eine gute Performance zu haben.

Datenschutz und Compliance

Datenverwendung

  • nJukebox speichert nur grundlegende Track-Metadaten
  • Keine Audiodaten werden lokal gespeichert
  • Spotify-Tokens werden sicher verwaltet

GEMA-Meldungen

Für Veranstaltungen in Deutschland:

  • Spotify-Streams werden in GEMA-Berichten erfasst
  • Automatische Erkennung von Spotify vs. lokalen Tracks
  • Vollständige Dokumentation für Rechteverwertung
