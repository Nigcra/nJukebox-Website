Was ist nJukebox?

nJukebox ist ein webbasiertes digitales Jukebox-System, das lokale MP3-Sammlungen mit Spotify-Streaming kombiniert. Es wurde speziell für Partys, Veranstaltungen und interaktive Musikerlebnisse entwickelt.

Hauptmerkmale

  • 🎵 Lokale Musikbibliothek: Verwalten Sie Ihre MP3-Sammlung
  • 🎤 Spotify-Integration: Streamen Sie Millionen von Songs
  • 🎨 Touch-freundlich: Optimiert für Touch-Displays
  • 🔐 Admin-Kontrollen: Vollständige Verwaltung der Wiedergabe
  • 📊 GEMA-Berichte: Compliance für deutsche Veranstaltungen
  • 🌍 Mehrsprachig: Deutsch und Englisch

Systemanforderungen

Minimal

  • Betriebssystem: Windows 10/11, macOS 10.15+, Linux
  • Node.js: Version 16 oder höher
  • RAM: 4 GB
  • Speicher: 1 GB für die Anwendung + Musiksammlung
  • Netzwerk: Internetverbindung für Spotify

Empfohlen

  • RAM: 8 GB oder mehr
  • CPU: Quad-Core Prozessor
  • Display: Touch-Display für beste Benutzererfahrung
  • Audio: Gute Lautsprecher oder Verstärker
  • Browser: Moderner Browser mit Widevine DRM-Unterstützung für Spotify (Chrome, Firefox, Safari, Edge)

Installation

Schritt 1: Node.js installieren

  1. Gehen Sie zu nodejs.org
  2. Laden Sie die LTS-Version herunter
  3. Führen Sie das Installationsprogramm aus
  4. Überprüfen Sie die Installation:
# Öffnen Sie eine Eingabeaufforderung/Terminal
node --version
npm --version

Schritt 2: nJukebox herunterladen

Sie haben zwei Möglichkeiten:

Option A: Git verwenden (empfohlen)

git clone https://github.com/Nigcra/nJukebox.git
cd nJukebox

Option B: ZIP herunterladen

  1. Gehen Sie zu GitHub Repository
  2. Klicken Sie auf "Code" → "Download ZIP"
  3. Entpacken Sie die Datei
  4. Navigieren Sie zum Ordner

Schritt 3: Abhängigkeiten installieren

npm install
Hinweis: Die Installation kann einige Minuten dauern, da alle erforderlichen Pakete heruntergeladen werden.

Schritt 4: Musik hinzufügen

  1. Kopieren Sie Ihre MP3-Dateien in den /music Ordner
  2. Organisieren Sie sie nach Belieben in Unterordnern
  3. Unterstützte Formate: MP3, FLAC, M4A, OGG

Schritt 5: nJukebox starten

Windows

Doppelklicken Sie auf eine der Batch-Dateien:

  • start_jukebox.bat - Startet die Hauptanwendung
  • start_data_server.bat - Startet nur den Datenserver

Linux/macOS

# Haupt-Jukebox
./start_jukebox.sh

# Oder manuell
node jukebox_server.js

Schritt 6: Zugriff auf nJukebox

  1. Öffnen Sie Ihren Webbrowser
  2. Gehen Sie zu http://localhost:3000
  3. Die nJukebox-Oberfläche sollte geladen werden
Erfolg! nJukebox läuft jetzt auf Ihrem System. Sie können Musik durchsuchen und zur Wiedergabeliste hinzufügen.

Erster Setup

Admin-Zugang

  1. Klicken Sie auf das Schloss-Symbol (🔒) oben links
  2. Geben Sie die Standard-PIN ein: 1234
  3. Das Admin-Panel öffnet sich
Sicherheit: Ändern Sie die Standard-PIN in den Admin-Einstellungen!

Bibliothek scannen

  1. Öffnen Sie das Admin-Panel
  2. Gehen Sie zum Tab "Einstellungen"
  3. Klicken Sie auf "Musik neu scannen"
  4. Warten Sie, bis der Scan abgeschlossen ist

Sprache wählen

  1. Im Admin-Panel → Einstellungen
  2. Wählen Sie "Deutsch" aus der Sprachliste
  3. Die Oberfläche wird sofort aktualisiert

Grundlegende Bedienung

Als Benutzer (Gast)

  • Musik durchsuchen: Verwenden Sie die Bibliothek-Tabs (Jahrzehnte, Genres)
  • Suchen: Verwenden Sie die Suchleiste oben
  • Titel hinzufügen: Klicken Sie auf einen Titel, um ihn zur Wiedergabeliste hinzuzufügen
  • Wiedergabeliste anzeigen: Klicken Sie auf den Wiedergabeliste-Tab

Als Administrator

  • Wiedergabe steuern: Play/Pause/Skip-Buttons
  • Lautstärke: Verwenden Sie den Lautstärkeregler
  • Wiedergabeliste verwalten: Titel entfernen oder neu anordnen
  • Einstellungen: System konfigurieren

Netzwerk-Setup

Lokaler Zugriff

Standardmäßig ist nJukebox nur lokal erreichbar (localhost:3000).

Netzwerk-Zugriff aktivieren

  1. Bearbeiten Sie config.json
  2. Ändern Sie "host": "localhost" zu "host": "0.0.0.0"
  3. Starten Sie nJukebox neu
  4. Zugriff über IP-Adresse: http://192.168.1.100:3000

Firewall konfigurieren

Windows

  1. Öffnen Sie Windows Defender Firewall
  2. Klicken Sie auf "App oder Feature durch Windows Defender Firewall zulassen"
  3. Fügen Sie Node.js hinzu oder erlauben Sie Port 3000

Problembehandlung

Häufige Probleme

Server startet nicht

  • Überprüfen Sie, ob Port 3000 bereits verwendet wird
  • Stellen Sie sicher, dass Node.js installiert ist
  • Führen Sie npm install erneut aus

Keine Musik sichtbar

  • Stellen Sie sicher, dass MP3-Dateien im /music Ordner sind
  • Führen Sie einen Bibliothek-Scan durch
  • Überprüfen Sie die Dateiberechtigungen

Kein Audio

  • Klicken Sie irgendwo auf die Seite (Browser-Autoplay-Richtlinie)
  • Überprüfen Sie die Systemlautstärke
  • Testen Sie mit verschiedenen MP3-Dateien
Weitere Hilfe: Schauen Sie in den Problembehandlungs-Leitfaden für detaillierte Lösungen.
