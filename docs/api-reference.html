Base URL

All API requests are made to:

http://localhost:3000/api

Authentication

Most endpoints require admin authentication. Include the admin PIN in requests:

// Headers
Authorization: Bearer YOUR_ADMIN_PIN

// Or as query parameter
?adminPin=YOUR_ADMIN_PIN
Public Endpoints: Some endpoints like library browsing and basic playback are available without authentication for regular users.

Library API

Endpoints for browsing and managing the music library.

GET/api/library

Get all tracks in the music library.

Query Parameters
Parameter Type Description
genre string Filter by genre
decade string Filter by decade (1980s, 1990s, etc.)
search string Search in title, artist, or album
limit number Maximum number of results
offset number Number of results to skip
Response
{
  "tracks": [
    {
      "id": 123,
      "title": "Song Title",
      "artist": "Artist Name",
      "album": "Album Name",
      "genre": "Pop",
      "year": 2020,
      "duration": 210,
      "file_path": "/music/artist/song.mp3",
      "cover_url": "/covers/123.jpg",
      "play_count": 5,
      "last_played": "2024-01-15T10:30:00Z"
    }
  ],
  "total": 1250,
  "page": 1,
  "limit": 50
}

GET/api/library/{id}

Get details for a specific track.

Path Parameters
Parameter Type Description

Response
{

  "title": "Song Title",
  "artist": "Artist Name",
  "album": "Album Name",
  "genre": "Pop",
  "year": 2020,
  "duration": 210,

  "is_local": true,

}

POST/api/library/scan

Trigger a library rescan. Requires admin authentication.

Request Body
{
  "force": false,
  "delete_missing": true
}
Response
{
  "status": "scan_started",
  "scan_id": "scan_20240115_103000",
  "estimated_time": 120

Playlist API

Manage the current playlist and queue.

GET/api/playlist

Get the current playlist.

Response
{
  "tracks": [
    {
      "id": 123,
      "title": "Song Title",
      "artist": "Artist Name",
      "duration": 210,
      "position": 0,
      "added_by": "user",
      "added_at": "2024-01-15T10:30:00Z"
    }
  ],
  "current_track": 0,
  "is_playing": true,
  "total_duration": 1800
}

POST/api/playlist/add

Add a track to the playlist.

Request Body
{
  "track_id": 123,
  "position": "end"
}
Response
{
  "status": "added",
  "position": 5,
  "message": "Track added to playlist"
}

DELETE/api/playlist/{position}

Remove a track from the playlist. Requires admin authentication.

Response
{
  "status": "removed",
  "message": "Track removed from playlist"
}

POST/api/playlist/clear

Clear the entire playlist. Requires admin authentication.

Response
{
  "status": "cleared",
  "message": "Playlist cleared"
}

WebSocket Events

Real-time events via WebSocket connection.

Connection

ws://localhost:3000/ws

Event Types

track_started

Fired when a new track begins playing.

{
  "event": "track_started",
  "data": {
    "track": {
      "id": 123,
      "title": "Song Title",
      "artist": "Artist Name",
      "duration": 210
    },
    "timestamp": "2024-01-15T10:30:00Z"
  }
}

track_ended

Fired when a track finishes playing.

{
  "event": "track_ended",
  "data": {
    "track_id": 123,
    "duration_played": 210,
    "timestamp": "2024-01-15T10:33:30Z"
  }
}

playlist_updated

Fired when the playlist is modified.

{
  "event": "playlist_updated",
  "data": {
    "action": "track_added",
    "track_id": 124,
    "position": 3,
    "total_tracks": 8
  }
}

library_updated

Fired when the library is rescanned.

{
  "event": "library_updated",
  "data": {
    "tracks_added": 15,
    "tracks_removed": 2,
    "total_tracks": 1250,
    "scan_duration": 45
  }
}

Error Responses

All endpoints may return the following error responses:

400 Bad Request

{
  "error": "Bad Request",
  "message": "Invalid parameters",
  "details": {
    "field": "track_id",
    "issue": "must be a number"
  }
}

401 Unauthorized

{
  "error": "Unauthorized",
  "message": "Admin authentication required"
}

404 Not Found

{
  "error": "Not Found",
  "message": "Track not found",
  "track_id": 999
}

500 Internal Server Error

{
  "error": "Internal Server Error",
  "message": "Database connection failed",
  "request_id": "req_123456"
}

Rate Limiting

API endpoints are rate limited to prevent abuse:

  • General endpoints: 100 requests per minute
  • Search endpoints: 30 requests per minute
  • Admin endpoints: 200 requests per minute
  • Playback control: 10 requests per minute
Rate Limit Headers: Check the X-RateLimit-Remaining and X-RateLimit-Reset headers to monitor your usage.

SDK and Libraries

JavaScript/Node.js

// Example usage with fetch
const api = {
  baseUrl: 'http://localhost:3000/api',
  
  async getLibrary() {
    const response = await fetch(`${this.baseUrl}/library`);
    return response.json();
  },
  
  async addToPlaylist(trackId) {
    const response = await fetch(`${this.baseUrl}/playlist/add`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ track_id: trackId })
    });
    return response.json();
  }
};

Python

import requests

class NJukeboxAPI:
    def __init__(self, base_url='http://localhost:3000/api'):
        self.base_url = base_url
        self.session = requests.Session()
    
    def get_library(self):
        response = self.session.get(f'{self.base_url}/library')
        return response.json()
    
    def add_to_playlist(self, track_id):
        data = {'track_id': track_id}
        response = self.session.post(f'{self.base_url}/playlist/add', json=data)
        return response.json()
