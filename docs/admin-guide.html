Accessing Admin Panel

  1. Click the lock icon (🔒) in the top-left corner of the interface
  2. Enter your admin PIN using the on-screen keypad
  3. Default PIN is 1234 (change this in production!)
  4. The admin panel will open with full system controls
Security: Always change the default PIN in production environments. The PIN controls access to system settings, music management, and reporting features.

Admin Panel Overview

The admin panel is organized into four main tabs:

⚙️ Settings

System configuration, Spotify setup, language settings, and basic controls

🎨 Appearance

Visual customization, themes, and visualization settings

🤖 Auto-Learning

Automatic playlist generation and music discovery features

📊 Reporting

Event management, play statistics, and GEMA reporting for German events

Settings Tab

Spotify Configuration

  • Connect/Disconnect: Manage your Spotify Premium account connection
  • Configuration: Set up Spotify Client ID for API access
  • Status Display: Real-time connection status indicator

Language Settings

  • German (Deutsch): Complete German interface
  • English: Full English translation
  • Changes apply immediately across the entire interface

Playback Controls

  • Track Lock Time: Prevent recently played tracks from being queued again (0-480 minutes)
  • Auto-DJ Mode: Automatically add tracks when the playlist is empty
  • Debugging Mode: Enable detailed console logging for troubleshooting

System Controls

  • Rescan Music: Re-index your music library for new files
  • Refresh Library: Update the interface with latest library changes
  • Database Cleanup: Remove orphaned records and optimize performance
  • Clear Database: Complete reset of all music data (use with caution)
  • Clear Cover Cache: Remove cached album artwork

Appearance Tab

Visualization Settings

Control the visual effects during music playback:

  • ⭐ Space: Starfield and cosmic effects
  • 🔥 Fire: Animated fire and flame effects
  • ✨ Particles: Dynamic particle systems
  • 🔵 Circles: Geometric circle animations

Visualization Controls

  • Switch Interval: How often visualizations change (5-300 seconds)
  • Auto-save: Settings are saved automatically
  • Fallback: When all effects are disabled, shows album cover colors

Auto-Learning Tab

Playlist Auto-Learning

Automatically discover and add popular music to your library:

Party Playlists

  • 🎵 Party Hits: Popular party and dance music
  • 🍺 Schlager Party: German party music and Schlager hits
  • 🕺 Dance Hits: Electronic dance music and club tracks
  • 🎉 All Party Playlists: Load all party categories at once

Custom Playlists

  • Add Custom Playlists: Import from Spotify playlist URLs
  • Manage Saved Playlists: View and organize your custom collections
  • Bulk Operations: Load all or delete multiple playlists
How Auto-Learning Works: The system connects to Spotify's API to discover popular tracks in various categories, then adds them to your local database for offline access and improved performance.

Reporting Tab

Event Information Management

Track and manage event details for reporting purposes:

  • Event Name: Name of your party or event
  • Organizer: Person or organization responsible
  • Location: Venue or address
  • Attendees: Number of participants

GEMA Reporting (Germany)

For events in Germany, generate reports for GEMA (music licensing):

  1. Fill in event information
  2. Set the date range for your event
  3. Click "Generate GEMA Report"
  4. Export the detailed play statistics
Legal Compliance: In Germany, public music performances require GEMA licensing. The reporting feature helps you comply with legal requirements by tracking played music.

Event Management

  • Save Events: Store event configurations for future use
  • Load Previous Events: Quickly set up similar events
  • Event History: Access past event reports and statistics

Audio & Queue Management

Playlist Controls

Admin users have additional controls for managing playback:

  • Start/Stop: Control music playback
  • Skip Track: Move to next song in queue
  • Clear Playlist: Remove all tracks from current queue
  • Quit: Stop system and clear all data

Volume Control

  • Master Volume: Control system-wide audio level
  • Fade Controls: Smooth transitions between tracks
  • Mute Function: Quickly silence all audio

User Management

Access Control

  • Admin vs. User Mode: Different interfaces for administrators and regular users
  • PIN Protection: Secure access to admin features
  • Session Management: Automatic logout and security features

User Restrictions

Regular users (non-admin) have limited access:

  • Can browse and add music to playlist
  • Cannot skip tracks or clear playlist
  • Cannot access system settings
  • Restricted by track lock times

Event Management Best Practices

Before the Event

  1. Test Everything: Verify audio, Spotify connection, and all controls
  2. Prepare Music: Use auto-learning to build appropriate playlists
  3. Set Lock Times: Configure appropriate restrictions for your event type
  4. Create Event Record: Set up event information for reporting

During the Event

  1. Monitor Playlist: Ensure music keeps flowing with auto-DJ
  2. Moderate Requests: Use admin controls to manage inappropriate additions
  3. Backup Plans: Have local music ready if Spotify connection fails
  4. Volume Management: Adjust levels as needed throughout the event

After the Event

  1. Generate Reports: Create GEMA reports if required
  2. Save Event Data: Store configuration for future similar events
  3. Clean Up: Clear playlist and reset system if needed
  4. Review Statistics: Analyze what music worked best
Pro Tip: Enable auto-DJ mode and set appropriate track lock times to create a smooth, self-managing music experience that keeps the party going without constant supervision.

Troubleshooting Admin Issues

Cannot Access Admin Panel

  • Verify you're using the correct PIN
  • Try refreshing the page
  • Check browser console for JavaScript errors
  • Restart the nJukebox system if needed

Settings Not Saving

  • Ensure you have admin privileges
  • Check network connection to the server
  • Verify the data server is running
  • Look for error messages in the admin panel
