🎛️ Admin Guide

Complete guide to nJukebox administration and event management

🎛️ Admin-Anleitung

Vollständiger Leitfaden zur nJukebox-Administration und Event-Verwaltung

Admin Panel Access

The admin panel provides full control over nJukebox settings, music management, and event features.

Accessing the Panel

  1. Click the lock icon (🔒) in the top-left corner
  2. Enter your admin PIN (default: 1234)
  3. The admin panel opens with multiple tabs
Security: Change the default PIN in production environments!

Settings Tab

Spotify Integration

  • Connect/disconnect your Spotify Premium account
  • Configure Spotify Client ID
  • View connection status

Language Settings

  • Switch between German and English
  • Changes apply immediately

Playback Controls

  • Track Lock Time: Prevent recently played tracks from being queued (0-480 minutes)
  • Auto-DJ Mode: Automatically add tracks when playlist is empty
  • Debug Mode: Enable console logging

Appearance Tab

Visualizations

  • ⭐ Space effects
  • 🔥 Fire animations
  • ✨ Particle systems
  • 🔵 Circle patterns

Reporting Tab

Event Management

  • Create and manage events
  • Track play statistics
  • Generate GEMA reports (Germany)
  • Export event data
Next Steps: Learn about advanced configuration options.

Admin-Panel Zugriff

Das Admin-Panel bietet volle Kontrolle über nJukebox-Einstellungen, Musikverwaltung und Event-Funktionen.

Panel öffnen

  1. Klicken Sie auf das Schloss-Symbol (🔒) oben links
  2. Geben Sie Ihre Admin-PIN ein (Standard: 1234)
  3. Das Admin-Panel öffnet sich mit mehreren Tabs
Sicherheit: Ändern Sie die Standard-PIN in Produktionsumgebungen!

Einstellungen Tab

Spotify Integration

  • Spotify Premium-Konto verbinden/trennen
  • Spotify Client ID konfigurieren
  • Verbindungsstatus anzeigen

Spracheinstellungen

  • Zwischen Deutsch und Englisch wechseln
  • Änderungen werden sofort angewendet

Wiedergabe-Steuerung

  • Track-Sperrzeit: Verhindert, dass kürzlich gespielte Titel erneut in die Warteschlange gestellt werden (0-480 Minuten)
  • Auto-DJ Modus: Fügt automatisch Titel hinzu, wenn die Playlist leer ist
  • Debug-Modus: Aktiviert Konsolen-Logging

Erscheinungsbild Tab

Visualisierungen

  • ⭐ Weltraum-Effekte
  • 🔥 Feuer-Animationen
  • ✨ Partikel-Systeme
  • 🔵 Kreis-Muster

Reporting Tab

Event-Verwaltung

  • Events erstellen und verwalten
  • Abspielstatistiken erfassen
  • GEMA-Reports generieren (Deutschland)
  • Event-Daten exportieren
Nächste Schritte: Erfahren Sie mehr über erweiterte Konfigurationsoptionen.
